# Software Testing Plan

## Project: All in One – Online Shopping 

## 1. Introduction

The Testing phase focuses on checking the functionality, reliability, and usability of the All in One application. It helps identify errors and verify whether the application meets its specified requirements.

## 2. Objectives of Testing

- Verify that application features work correctly.
- Identify and report software errors.
- Check the interaction between application modules.
- Verify that user data is handled correctly.
- Ensure that the application provides a smooth user experience.

## 3. Scope of Testing

The testing activities cover the following modules:

1. User registration and login.
2. Product categories and product browsing.
3. Product search.
4. Favourites management.
5. Shopping cart management.
6. Checkout and payment options.
7. Delivery location selection.
8. Delivery agent profile submission.
9. Order management and order history.

## 4. Types of Testing

| Testing Type | Description |
|---|---|
| Functional Testing | Checks whether each application feature works as expected. |
| UI Testing | Checks screen layouts, buttons, navigation, and user interactions. |
| Integration Testing | Checks communication between application modules and Firebase services. |
| Validation Testing | Checks whether the application accepts valid data and handles invalid inputs. |
| Performance Testing | Checks application response time and loading behavior. |
| Compatibility Testing | Checks application behavior on supported Android devices and versions. |

## 5. Testing Approach

The team will perform the following activities:

1. Prepare test cases for each major application feature.
2. Execute test cases using valid and invalid inputs.
3. Record actual results and compare them with expected results.
4. Report errors and unexpected behavior.
5. Fix identified problems.
6. Retest the affected functionality.

## 6. Expected Outcome

Testing should help identify defects, improve application stability, and confirm that the implemented features work according to their requirements.

## 7. Conclusion

The Testing phase is important for improving the quality and reliability of the All in One application. It helps the development team identify problems and verify the application before final delivery.
