# RACI Matrix

## 1. Introduction

This RACI Matrix defines the roles and responsibilities of the three team members working on the All in One – Online Shopping and Multi-Vendor Delivery Ecosystem project.

**RACI Meaning:**
- **R – Responsible:** Performs the task.
- **A – Accountable:** Takes ownership of the task.
- **C – Consulted:** Provides advice or support.
- **I – Informed:** Receives project updates.
