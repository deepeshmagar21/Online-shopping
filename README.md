# All in One – Online Shopping

## 1. Project Overview

**All in One – Online Shopping** is an Android-based shopping application designed to bring different categories of products together on a single platform.

The application aims to make online shopping easier and more convenient by allowing customers to explore products from different categories, including clothing, food, groceries, electronics, gadgets, footwear, and other daily necessities.

Instead of using multiple shopping applications, customers can access different types of products through one application.

## 2. Project Objectives

The main objectives of this project are:

- To provide a centralized online shopping platform.
- To allow customers to browse products from different categories.
- To make product searching easier and faster.
- To provide shopping cart and order management functionality.
- To simplify the online shopping experience.
- To connect customers with different vendors through one platform.

## 3. Main Features

The project is designed around the following features:

- **User Authentication:** Customer registration and login.
- **Product Browsing:** Explore products from different categories.
- **Product Search:** Search for available products.
- **Shopping Cart:** Add, remove, and manage cart items.
- **Favourites:** Save preferred products.
- **Order Management:** Place and manage shopping orders.
- **Location Services:** Support location-related functionality.
- **Vendor Management:** Support vendor-related product and order operations.

*Note: The availability and completion status of individual features should be verified against the current application.*

## 8. Getting Started

To explore and work with this project:

1. Clone or download the repository.
2. Open Android Studio.
3. Select **Open** and choose the downloaded project folder.
4. Allow Gradle synchronization to complete.
5. Configure the required Firebase project settings.
6. Build and run the application using an Android device or emulator.
