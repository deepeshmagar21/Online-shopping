# Feasibility Study

## Project: All in One – Online Shopping 

## 1. Introduction

The feasibility study evaluates whether the All in One application can be developed successfully using the available technology, team resources, budget, and project schedule. It examines the technical, economic, operational, and schedule feasibility of the project.

## 2. Technical Feasibility

The project is technically feasible because it uses available development tools and technologies.

- **Development Platform:** Android Studio is used for Android application development.
- **Programming Language:** Java/Kotlin is used for application development.
- **Authentication:** Firebase Authentication supports user registration and login.
- **Database:** Firebase Firestore is used to store and manage application data.
- **Cloud Storage:** Firebase Storage can be used to store product images and other files.
- **Maps and Location:** Google Maps and Google Play Services Location support location-related features.
- **Payment:** Pay on Delivery and debit/credit card payment options are planned for checkout.

These technologies provide the necessary tools to develop the main features of the application.

## 3. Economic Feasibility

The project is economically feasible because it can be developed using existing computers, internet access, and available development tools.

- Android Studio is available for application development.
- Firebase provides free usage allowances, subject to service limits.
- GitHub can be used for source code management and collaboration.
- The team can use available development resources to reduce project costs.

Some services, such as payment processing, maps usage, and additional cloud resources, may involve costs depending on usage and service plans.

## 4. Operational Feasibility

The application is designed to be useful and convenient for different users.

- **Customers:** Can browse products from different categories, search for items, manage carts, and place orders.
- **Vendors:** Can use the platform to make their products available to customers.
- **Delivery Personnel:** Can submit their profiles for delivery-related activities.

The application aims to simplify shopping by bringing multiple product categories and vendors together in one platform.

## 5. Schedule Feasibility

The project is planned according to a 12-week development schedule.

The schedule includes:

- Project initiation and requirement analysis.
- System architecture and UI/UX planning.
- Database and application development.
- Product browsing, search, and cart implementation.
- Checkout, payment, and location-related features.
- Testing, documentation, and final review.

The planned schedule provides a structured approach for completing the project within the available development period.

## 6. Conclusion

Based on the technical resources, available development tools, team capabilities, estimated costs, and planned schedule, the All in One application is considered feasible as an academic software development project. Successful completion will depend on proper teamwork, implementation, testing, and management of project resources.
